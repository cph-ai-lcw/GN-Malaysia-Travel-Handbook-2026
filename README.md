# GN Malaysia Travel Handbook 2026

國能馬來西亞旅遊 2026 單一 HTML 行動旅遊手帳。

## 使用方式

1. 將 `index.html` 上傳至 GitHub repository 根目錄。
2. 到 Settings → Pages。
3. Source 選擇 Deploy from a branch。
4. Branch 選擇 `main` 與 `/ (root)`。
5. 儲存後等待 GitHub Pages 發布。
